# ICML 2026 draft

The unmodified official ICML 2026 author kit was downloaded from
https://media.icml.cc/Conferences/ICML2026/Styles/icml2026.zip
(SHA-256 `8b29290f5828e176debb57ea9cc00252502973d55ea561a2f18a7f0a326bfc6c`).
`main.tex` and `references.bib` are this project's draft, not part of that kit.

Build: `latexmk -pdf main.tex`. The compiled `main.pdf` is a draft. The
one-seed online Jev/GRPO pilot is complete, but formal claims still require
multi-seed replication and broader held-out evaluation. The preregistered
formal run specification is executable from `../../config/config..yaml`; no
formal result has been added to the paper yet.
